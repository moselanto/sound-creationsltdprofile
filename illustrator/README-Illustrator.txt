SOUND CREATIONS LTD - COMPANY PROFILE 2026 - ILLUSTRATOR PACKAGE
================================================================

WHAT IS IN THIS FOLDER
  svg/      19 pages, one file per page (297 x 210 mm). Open these in Illustrator.
  fonts/    Space Grotesk and Inter (static TTF, SIL Open Font License).
  images/   Every photo and logo used, at full original resolution.
  Sound-Creations-Company-Profile.pdf   The finished print PDF (reference / proof).
  open-all-in-illustrator.jsx           Optional script: converts all 19 SVGs to .ai files.

STEP 1 - INSTALL THE FONTS FIRST
  Install every .ttf in fonts/ (double-click > Install), then restart Illustrator.
  Without them Illustrator substitutes a default font and the text will not match.

STEP 2 - OPEN A PAGE
  Illustrator > File > Open > svg/Page-01-Cover.svg (and so on).
  Each page opens as one artboard of 297 x 210 mm with:
    - Layers named by part: Background, Photo, Red glow, Cover title, Content,
      Project write-up, Brand logos, Map and offices, Logo, Header label, Footer, etc.
    - Sub-groups inside each layer named after the design element (card, eyebrow, fx-meta ...).
    - Live, editable text: every line is one text object; coloured words are separate runs.
    - Vector cards, lines, badges, gradients and the red sound wave.
    - Photos embedded at full resolution and masked to their frames (clipping masks).

STEP 3 (OPTIONAL) - CONVERT ALL PAGES TO .AI IN ONE GO
  Illustrator > File > Scripts > Other Script... > open-all-in-illustrator.jsx
  Choose the svg folder; it saves Page-01 ... Page-19 as .ai files in an "ai" folder next to it.

TIPS
  - Text with letter spacing (labels in capitals) keeps its tracking.
  - To swap a photo: select it in the Layers panel > Relink/replace, or drop in a new image and
    use Object > Clipping Mask > Make with the existing frame.
  - Some photos come from the original 2026 PDF and are 100-150 ppi at full-page size. They print
    acceptably but supplying the original camera files will make print sharper (see list below).
